# Руководство редактора: Google Drive проектной папки

Единая закрытая папка для фотографий и документов архива. Структура вложенных подпапок — любая удобная; сайт ориентируется на `driveFileId` файла, а не на путь.

## Устройство

1. Владелец создаёт одну **проектную папку** (например, «Семейный архив Логвиновых — материалы») и выдаёт редакторам доступ.
2. Внутри можно заводить подпапки по ветвям/годам — перенос файла между папками **не ломает** ссылку в таблице.
3. Файлы **не переводятся** в режим «доступно всем, у кого есть ссылка»: это обошло бы защиту сайта.

## Порядок добавления материала

1. Загрузите файл в проектную папку (штатной кнопкой «Создать/Загрузить» или перетаскиванием).
2. Скопируйте ссылку на файл (ПКМ → «Получить ссылку» → доступ «Ограниченный»).
3. Вставьте ссылку в `Media.sourceUrl` — `driveFileId` и `storage` заполнятся автоматически (или меню «Заполнить недостающие ID»).
4. Заполните `title`, `category`, `visibility`, описание (`publicCaption`/`familyCaption`), `altText`.
5. При необходимости свяжите материал с человеком во вкладке `PersonMedia`.

## Рекомендации по файлам

- **Размер**: до 8 МБ жёсткий предел, рекомендуемые оптимизированные копии 2–3 МБ (приватный файл передаётся через base64 и увеличивает объём ответа).
- **Форматы**: JPEG/PNG/WebP/GIF/SVG, PDF. Приватные PDF открываются на сайте по кнопке «Открыть документ».
- **Приватные превью**: сканируйте в разумном разрешении; оригиналы высокого разрешения можно хранить в папке «Оригиналы», не вставляя её файлы в таблицу.

## Публичные материалы в Drive

Допускается: `visibility = PUBLIC` + файл в проектной папке **с включённым доступом «Все в интернете, у кого есть ссылка»**. Такие материалы считаются намеренно общедоступными; сайт отдаёт прямую ссылку чтения. Публичные файлы большого размера лучше выносить во внешнее хранилище или оптимизировать.

## Внешние ссылки

`sourceUrl` на внешний `https://`-адрес допустим для обоих видов видимости. Ограничения: сервис может запрещать встраивание, удалять файлы или давать временные ссылки — сайт покажет заглушку, галерея не сломается. Важные материалы храните копией в проектном Drive.

## Что нельзя

- Публиковать приватный файл ссылкой «для всех» — защита сайта перестаёт работать.
- Хранить пароли/доступы в именах файлов или описаниях приватных материалов.
- Удалять файл, оставляя строку в `Media`: материал перестанет открываться; пометьте строку `status = DRAFT` и удалите ссылку.
