# Руководство редактора: Google Drive проектной папки

Единая закрытая папка для документов архива и «рабочая» папка для фото. Структура вложенных подпапок — любая удобная; сайт ориентируется на ID файла в ссылке, а не на путь.

## Простое правило

| Что добавляете | Куда вставляете ссылку | Доступ к файлу на Drive |
|---|---|---|
| **Фото** (аватар в «Люди» → «Фото»; материал с категорией «Фотоархив»/«Портреты») | публичная ссылка: файл Drive **с доступом «Все, у кого есть ссылка → Читатель»** или любой внешний https | включён «по ссылке» |
| **Документ** (категория «Документы») | ссылка на **закрытый** файл Drive | «Ограниченный» — публиковать не нужно |

Ссылка — всегда на **файл** (ПКМ по файлу → «Получить ссылку»), не на папку: `https://drive.google.com/file/d/…/view`.

Почему так: фото показываются в древе и галерее напрямую из браузера посетителя, поэтому файлу нужен доступ «по ссылке» — сервер превращает её в прямую картинку сам. Документы сайт читает на сервере от имени владельца и отдаёт только после семейного входа, поэтому их публикация не нужна и не нужна вовсе.

## Устройство папки

1. Владелец создаёт **проектную папку** (например, «Семейный архив — материалы») и выдаёт редакторам доступ.
2. Внутри подпапки по ветвям/годам: перенос файла между папками **не ломает** ссылку в таблице.
3. Файлы, которые должны оставаться закрытыми, не переводятся в режим «доступно всем, у кого есть ссылка».

## Порядок добавления материала

1. Загрузите файл в проектную папку (кнопка «Загрузить» или перетаскиванием).
2. Скопируйте ссылку на файл и вставьте в колонку «Ссылка» листа «Материалы» (или «Фото» листа «Люди»).
3. Заполните название, категорию, видимость, подпись; при необходимости — «Чей материал».
4. Меню «Семейный архив → Проверить данные»: ошибки ссылок видны сразу.

## Рекомендации по файлам

- **Приватные документы**: до 8 МБ жёсткий предел, рекомендуемые копии 2–3 МБ (файл передаётся через base64).
- **Фото**: JPEG/WebP 1000–2000 px по большей стороне — сайт запрашивает у Drive сжатую копию нужной ширины.
- **Форматы**: JPEG/PNG/WebP/GIF/SVG, PDF. Приватные PDF открываются на сайте по кнопке «Открыть документ».
- Оригиналы высокого разрешения храните в подпапке «Оригиналы», не вставляя их в таблицу.

## Что важно помнить

- «Семейное» фото тоже лежит за доступом «по ссылке»: сайт не показывает его без входа, но сам файл теоретически открываем по прямой ссылке. Подлинно закрытыми остаются только документы (категория «Документы»).
- Публиковать приватный документ «для всех» нельзя — защита сайта перестаёт работать.
- Удалять файл, на который ссылается строка таблицы, нельзя — материал перестанет открываться. Вместо этого чекбокс «Черновик».
- Внешние https-ссылки допустимы для обоих видов; сервис может удалять файлы или запрещать встраивание — важное храните копией в Drive.
