# Руководство редактора: Google Sheet семейного архива

Для родственников, которые наполняют архив. Три листа — «Люди», «События», «Материалы», — никаких технических таблиц. Доступ редактора выдаёт владелец; семейный пароль сайта здесь не нужен.

## Золотые правила

1. **Даты — как удобно**: `1890`, `1937-03`, `1937-03-14`, по-русски `14.03.1937`. Если Sheets сам превращает ввод в дату (число «уезжает» вправо) — ничего не страшного, сайт понимает и такие ячейки. Полные даты (с днём) дополнительно попадают в карточку «В этот день» на главной: годовщины рождения, дни памяти и памятные события.
2. **№ человека** — это его адрес в архиве. Проставляется сам при вводе ФИО (или меню «Проставить номера»). Не меняйте существующие №: на них ссылаются родственники и материалы.
3. **Родство** — одна колонка на связь: кликните «Отец» / «Мать» / «Супруг(а)» / «Человек» / «Чей материал» и выберите из списка значение вида **«3 · Иван Иванович Логвинов»** — сразу видно, кого выбираешь.
4. **Видимость**: «Публичное» — видят все; «Семейное» — только после семейного входа. Подробности живых всегда семейные, что бы ни было выбрано.
5. Публичные поля умерших публикуются автоматически. Закрыть карточку умершего — «Видимость карточки» = Семейная.
6. Изменения публикуются **сразу** — при следующей загрузке страницы сайта. Уже открытую страницу обновите (F5). Меню «Обновить публичный кэш» — страховка для случаев, когда данные меняются формулами/внешними источниками (они не вызывают автопубликацию).
7. Ошибочная строка не ломает сайт — она исключается и попадает в «Отчёт проверки» (меню «Проверить данные»).
8. Скрыть запись временно — чекбокс «Черновик». Строки можно и удалять.

## Лист «Люди» (одна строка = один человек)

| Колонка | Что заполнять |
|---|---|
| № | автоматически; не менять |
| ФИО | полное имя как в архиве; повторы ФИО допустимы — различает № |
| Дата рождения / смерти | `1890`, `1937-03`, `1937-03-14`, `14.03.1937`; у живых смерть пустая |
| Живой | чекбокс |
| Ветвь | подпись ветви, например «Ветвь Ивана»; у общих предков — их собственная (появится в фильтре) |
| Отец / Мать / Супруг(а) | выпадающий список «№ · ФИО» |
| Публичная / Семейная биография | текст; семейная видна только после входа |
| Место рождения (публичное/семейное), Контакты, Заметки | по необходимости |
| Фото | публичная ссылка на файл: Google Drive (включите «Все, у кого есть ссылка → Читатель»), любой https-адрес или путь `assets/portrait-*.svg`; пусто — нейтральная заглушка. Аватар виден всем visitors сайта |
| Видимость карточки | пусто (авто) / Семейная / Публичная |
| Черновик | чекбокс «скрыть с сайта» |

## Лист «События»

Рождения и смерти заполнять **не нужно**: сайт сам выводит их в хронологию из дат листа «Люди» — компактными строками с маркерами `*` (рождение) и `†` (смерть), по клику открывается карточка человека. Видимость та же, что у карточки человека: живые и «Семейная» — только после входа. Ручная строка о том же человеке с тем же годом заглушит автостроку — так можно оставить особое описание.

Сюда записывайте события, которые не выводятся автоматически: браки, переезды, семейные вехи и исторический контекст.

| Колонка | Что заполнять |
|---|---|
| Дата / Конец | год или полная дата (`1941`, `1941-06`, `22.06.1941`); «Конец» — для диапазонов (1941…1945). Полная дата с днём (например годовщина свадьбы) попадает в «В этот день» |
| Отображать как | как показать дату: «1941–1945», «1970-е»; пусто — соберётся сам |
| Заголовок / Описание | текст события |
| Тип | Семейное / Историческое (цвет маркера) |
| Видимость | Публичное / Семейное |
| Человек | к кому относится (список «№ · ФИО»); пусто — общее событие |

## Лист «Материалы»

| Колонка | Что заполнять |
|---|---|
| Название / Подпись | заголовок и краткая подпись |
| Дата | для сортировки и показа («1930-е» допустимо) |
| Категория | Фотоархив / Документы / Портреты (фильтр галереи) — от неё зависит, как читается «Ссылка» из Drive |
| Видимость | Публичное / Семейное |
| Ссылка | **фото** (Фотоархив/Портреты): публичная ссылка — файл Drive с доступом «по ссылке» или внешний https. **Документы**: ссылка на закрытый файл Drive (без публикации) до 8 МБ — сайт сам прочитает его и покажет только семье |
| Локальный путь | для заглушек сайта: `assets/archive-family.svg` и т.п. |
| Чей материал | выпадающий список «№ · ФИО» |
| Роль | Портрет / Галерея / Документ |

Ссылка — всегда на **файл** (ПКМ → «Получить ссылку»), не на папку. Приватный документ Drive: до 8 МБ (лучше 2–3 МБ), в проектной папке — см. `docs/drive-guide.md`.

## Меню «Семейный архив»

- **Проставить номера людям** — заполнит пустые № (обычно не нужно: они появляются сами).
- **Проверить данные** — отчёт на листе «Отчёт проверки»: вкладка, строка, №, код, понятное описание.
- **Обновить публичный кэш** — немедленная публикация изменений.
- **Обновить списки подстановки** — пересобрать выпадающие списки (после больших перестановок или если новый человек не появился в списке).
- **Активные сессии (число)** — сколько семейных входов сейчас действует.

## Частые вопросы

**Добавила человека, № не появился.** Введите ФИО и нажмите Enter — № появится сам (или меню «Проставить номера»). Если человек есть, а в списке подстановки его нет — меню «Обновить списки подстановки».

**Файл из Drive не открывается после входа.** «Проверить данные»: ссылка должна быть вида `https://drive.google.com/file/d/…/view` (на файл, не на папку). Документ — в проектной папке, до 8 МБ. Фото из Drive не показывается? — проверьте, что файлу включён доступ «Все, у кого есть ссылка → Читатель».

**Карточка умершего видна всем.** Так задумано; закрыть — «Видимость карточки» = Семейная.

**Как переименовать ветвь?** Просто поменяйте текст в колонке «Ветвь» — фильтр древа соберётся из данных заново. При выборе ветви на древе всегда видны её люди, их предки (до самых корней) и супруги — так что у отфильтрованных сохраняются родительские связи.
