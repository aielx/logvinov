# Руководство владельца (admin)

Закрытые операции, которые выполняет только владелец аккаунта Google из редактора Apps Script. Учетные данные и семейный пароль не попадают в Git и CI.

## Семейный пароль

Один общий пароль; персональные аккаунты не создаются. Требование: не короче 10 символов; длинная запоминающаяся фраза надёжнее набора символов.

**Установка/смена** (редактор Apps Script, функция внизу `Code.ts`):

```js
setFamilyPasswordAndRevoke("новая-длинная-семейная-фраза")
```

- создаётся новая соль, хеш PBKDF2-HMAC-SHA256 (2000 итераций) уходит в Script Properties;
- `AUTH_EPOCH` увеличивается — **все прежние сессии отзываются немедленно**;
- пароль передаётся владельцу семьи отдельным защищённым каналом (не email в открытом виде), запросы доступа — через `logvinovaleksander@gmail.com`.

## Сессии

- Хранения токена в открытом виде на сервере нет: только `SHA-256(токен)` + дата создания + эпоха в Script Properties (ключ `SESSION_<hash>`).
- TTL нет: сессия живёт до logout, смены пароля, глобального отзыва или очистки браузера.
- **Глобальный отзыв без смены пароля**:
  ```js
  revokeAllSessions()
  ```
- Число активных сессий — меню таблицы «Семейный архив → Активные сессии (число)».
- Записи прежних эпох удаляются автоматически при каждом входе (`cleanupStaleSessions`), квота Script Properties не расходуется.

## Защита от перебора

- 5 неудачных попыток в 15 минут → глобальная блокировка входа (прикладной 429 с `retryAfterSeconds`).
- Экспоненциальная задержка ответа на повторные ошибки (до 2 с).
- Лимит приватных медиазапросов: 120 в 5 минут.
- Ограничение: надёжного IP клиента в Apps Script нет — лимиты глобальные (см. `docs/threat-model.md`).

## Структура таблицы

- `setup()` — создать вкладки/заголовки/защиту/демо-данные (безопасен при повторном запуске, данные не перезаписывает).
- Демо-данные можно удалить после переноса реальных (строки целиком, `status = DRAFT` не нужен для удаления демо — это просто строки).
- `SPREADSHEET_ID` в Script Properties заполняется `setup()` (для автономного проекта; контейнерному не нужен).

## Версионирование API

1. Изменения кода: `clasp push` → в редакторе **Развернуть → Управление развёртываниями → Изменить → Новая версия**.
2. `/dev` URL — только для разработки владельцем; GitHub Pages всегда использует версионированный `/exec`.
3. Откат: назначить предыдущую версию тому же развёртыванию, затем очистить кэш меню «Обновить публичный кэш».
4. Frontend и API согласованы по `apiVersion` (`1`); несовместимые изменения — новая версия + обновление `src/lib/api/client.ts`.

## Что проверять регулярно

- «Проверить данные» после каждой волны правок родственников.
- Вкладку «Отчёт проверки»: коды `*_DUPLICATE`, `REL_CYCLE`, `PERSON_LIVING_WITH_DEATH` требуют внимания.
- Квоты Apps Script (Executions в консоли) при всплесках обращений.
- Резервные копии по графику `docs/backup-restore.md`.
