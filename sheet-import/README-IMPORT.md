# Импорт демо-данных архива в Google Sheet

Три CSV — три простых листа таблицы (схема v2): **Люди**, **События**, **Материалы**. Никаких технических таблиц со связями: родство указывается номером человека из выпадающего списка.

Демо-набор: 10 человек, 12 событий, 10 материалов. Закрытые строки помечены «СЕМЕЙНЫЕ ДАННЫЕ (CANARY …)» — при переносе реальных данных их не будет.

## Порядок импорта

1. Создайте новую пустую Google Sheet («Семейный архив Логвиновых»).
2. **Файл → Импорт → Загрузка**: выделите все 3 CSV.
3. Для каждого файла:
   - **Место вставки**: «Вставить новый лист» (первый — можно «Создать таблицу»);
   - **❗ Снимите галочку «Преобразовать текст в числа, даты и ссылки»** — иначе Sheets исказит даты вида `1937-03`.
4. Листы получат имена из файлов — так и нужно (Люди, События, Материалы). Удалите пустой «Лист1».

## Дальше (обязательный шаг для работы сайта)

По `docs/deployment.md`, шаги 1–3:

1. **Расширения → Apps Script** → загрузить код из `apps-script/` (clasp или копированием файлов).
2. Выполнить `setup()` — она добавит лист «Инструкция», чекбоксы и выпадающие списки связей
   (**Отец / Мать / Супруг(а) / Человек / Чей материал** — выбор сразу по «№ · ФИО», например «3 · Иван Иванович Логвинов»)
   и не тронет импортированные данные.
3. Задать пароль: `setFamilyPasswordAndRevoke("ваша-длинная-фраза")` в редакторе.
4. Развернуть Web App (от имени владельца, доступ «Все»), проверить `prototype/api-smoke.html`.

## Как заполнять (коротко)

- **№** у нового человека проставится сам при вводе ФИО (или меню «Семейный архив → Проставить номера»).
- **Отец/Мать/Супруг(а)**: выберите человека из выпадающего списка — в ячейке будет «№ · ФИО».
- Даты: `1890`, `1937-03`, `1937-03-14`. У живых пустая «Дата смерти» и включён чекбокс «Живой».
- Видимость: «Публичное» / «Семейное». Подробности живых всегда семейные.
- Скрыть запись временно — чекбокс «Черновик».

Проверка после импорта: меню «Семейный архив → Проверить данные» → «Ошибок нет».
